Elsewhere · Règles du jeu

Toutes les règles qu’Elsewhere applique, domaine par domaine : ce que fait chaque règle, ses nombres et son calcul, le fichier et le symbole du code qui l’appliquent, et si elle suit RimWorld 1.6 (jeu de base) ou une adaptation. Les nombres et les tableaux sont lus dans le code du jeu à l’ouverture de la page ; une règle écrite à la main ne contient aucun nombre qui ne vienne du code. Page de référence seulement : elle ne charge aucune partie.

Comme le jeu de base même règle que RimWorld 1.6. Adaptation règle adaptée, expliquée dans la note. Propre à Elsewhere sans équivalent dans RimWorld.
